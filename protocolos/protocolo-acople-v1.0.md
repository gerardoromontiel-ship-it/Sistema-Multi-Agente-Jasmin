## 🔄 Ciclo de Sincronización

1. **Pull** → Descargar últimos cambios del repositorio
2. **Revisar** → Leer protocolos y tareas asignadas
3. **Procesar** → Ejecutar tareas según rol
4. **Push** → Subir archivos generados
5. **Reportar** → Enviar reporte de estado a #estado (Discord)

**Frecuencia:** Cada 5 minutos o cuando haya cambios
